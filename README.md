## 💡 프로젝트 주제 선정

**클론코딩: 이스트캠프 홈페이지 (Remaster)**

선택 이유:

- Figma를 활용한 목업 디자인과 HTML 마크업, CSS 스타일링을 연습하기에 난이도가 적절했습니다.
- 팀 토이 프로젝트이긴 하지만 클론코딩 배포 후 저작권 이슈가 생길 가능성을 고민했습니다. 확률은 아주 낮지만 최악의 경우를 대비하고 싶어서, 리스크가 없는 현재 소속 부트캠프인 '이스트캠프'의 공식 홈페이지를 선택했습니다.
- 처음에는 이스트소프트 본사 홈페이지와 이스트캠프 홈페이지를 두고 고민했는데, 이스트캠프 홈페이지의 퀄리티가 다소 아쉬웠습니다. 이 아쉬움을 직접 해소해보고 싶어서 이스트캠프 홈페이지 Remaster로 방향을 정했습니다.

## 🛠️ 기술 스택 선정

- **마크업:** HTML5
- **스타일:** CSS3

선택 이유:

- 1차 팀프로젝트 요구사항에 기술 스택 제한이 있었습니다.
- React/Next 같은 프론트엔드 프레임워크는 아직 수업에서 다루지 않아 마크업은 HTML 외에 선택지가 없었습니다. 반면 CSS는 바닐라 CSS3, Sass/SCSS, Bootstrap, TailwindCSS 네 가지 선택지가 있었습니다. 그중 CSS3를 고른 이유는, 모든 CSS 프레임워크의 근본이 결국 CSS3이기 때문에 학습 초창기에는 근본을 쌓는 것이 더 옳은 판단이라고 생각했기 때문입니다. 바닐라 CSS3를 유연하게 다룰 수 있으면 이후 어떤 CSS 프레임워크도 자연스럽게 습득할 수 있을 것이라 판단했습니다.

## 🎨 디자인 시스템 선정

### Figma

수업에서 다룬 디자인 시스템 툴이 Figma 하나뿐이라 사실 선택의 여지는 없었습니다. 다만 왜 Figma를 써야 하는지는 수업을 통해 확실히 이해할 수 있었습니다.

### 디자인 토큰 → CSS 변환 관리 방식

디자인 토큰(JSON)을 CSS로 변환하여 관리하는 방법으로는 **NPM 배포 방식**과 **Local 빌드 방식** 두 가지를 검토했고, 그중 **Local 빌드 방식**을 선택했습니다.

- **적용 환경:** 웹 브라우저 단일 대상 프로젝트이거나 모노레포 구조.
- **구조:** 별도의 CI 빌드나 외부 npm 배포 없이, 웹 프로젝트의 Git Repository 안에 JSON 파일 그대로 커밋을 받는다.
- **흐름:** 개발자가 최신 JSON이 들어온 Git Commit을 `git pull` 받은 다음, 로컬에서 `npm run dev`나 `npm run build`를 실행할 때 빌드 스크립트(Pre-script)가 JSON을 읽어서 CSS 파일로 자동 변환해 둔다.
- **선택 이유:** CI 서버 실행 비용을 0원으로 아낄 수 있고, 복잡한 배포 파이프라인을 관리할 필요도 없어서 현재 프로젝트 규모에서는 가장 합리적인 방식이라고 판단했습니다.

## 💾 Git 컨벤션

### 브랜치 규칙

| 종류   | 예시                         | 용도                    |
| ------ | ---------------------------- | ----------------------- |
| 잡일   | `somang-chore/readme-update` | 리드미 업데이트         |
| 마크업 | `somang-style/header`        | 헤더 마크업/스타일 작업 |
| 픽스   | `somang-fix/header`          | 헤더 버그 수정          |
| 리팩   | `somang-refactor/header`     | 헤더 컴포넌트 최적화    |

### 커밋 메시지 접두어

- `chore`: 잡일 기록용
- `style`: 마크업/스타일 관련
- `fix`: 버그, 에러 수정 관련
- `refactor`: 수정 또는 최적화 관련

### 왜 'style'을 마크업/스타일 작업에 쓰기로 했나

마크업/스타일 작업의 일반적인 권장 접두어는 `feature`이지만, 팀과 협의해서 컨벤션을 직접 바꿔보는 경험도 중요하다고 생각했습니다. 팀원들과 원활히 합의한 끝에 `style`을 마크업/스타일 전용 접두어로 쓰기로 했습니다.
